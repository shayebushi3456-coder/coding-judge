在当前代码库把状态管理缺的几块能力补上。

异步请求相关的 action 要能认出来：进行中、成功、失败、主动带值失败这些状态，以及是不是某几个异步流程发出来的，都要能判断。有时要命中其中一个条件就行，有时得几个条件同时成立，普通 action 和判断函数混着用也行。

订阅这边一连串不那么急的更新别每次都刷界面，攒一波再通知出去。可以用微任务、定时器、动画帧，或者自己丢个排队回调来控制。给 action 打低优先级标记的辅助也要有，默认装进 store 的那套增强别断。
